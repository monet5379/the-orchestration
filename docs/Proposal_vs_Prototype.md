# 기획서 vs HTML 프로토타입 차이

> **기획서:** [The_Orchestration_Game_Proposal.pptx.txt](./The_Orchestration_Game_Proposal.pptx.txt)  
> **프로토타입:** [`../prototype/`](../prototype/) · **현재 v0.1.30**  
> **아키텍처:** [HTML_Prototype_Structure.md](./HTML_Prototype_Structure.md)

이 문서는 **기획서에 명시된 것**, **프로토타입에만 있는 것**, **의도적으로 다르게 만든 것**을 구분합니다.  
엄격히 기획서만 따르지 않고, USP는 유지한 채 빈칸·기술·UX는 협업·제안으로 채웁니다.

## 2. 기획서에 있고 프로토타입에 반영된 것

| 기획서 | 프로토타입 |
|---|---|
| 가위/바위/보 비밀 선택 | `[가위][바위][보]` 버튼 |
| 「승자 있음 / 무승부」만 공개 | `#ceiling-screen` (높이 100px 고정 슬롯) |
| 5초 수정 페이즈 | ADJUST + 게이지·카운트다운 (**15s**, 시간 팽창 +2s) |
| 한정 자원으로 패 수정 | 수정권 (기본 2, 가면으로 +1 가능) |
| 페이크 블러핑 (소리·연출) | `[페이크]` 자원 소모 · **상대 페이크**만 `audio.js` + POV 플래시 (내 수정·페이크는 무연출) |
| 패배 시 형벌 누적 (3회) | `penalties: 0→3`, `getBalance().match.maxPenalties` (`balance.js`) |
| 무승부 → 테이블 아이템 | `TIE_LOOT` + `#tie-loot-panel` |
| 「본능」「시간 팽창」 등 룰 왜곡 | instinct / time_warp / **rule_break** (1턴) |
| 1:1 대전 | CPU (`ai/opponent.js`) |
| 가면 수집·영구 해금 | `masks.js` + `storage.js` / localStorage |
| 독방 + VHS 캠코더 복기 | `#cell-root` + `vhs-player.js` + `replay.js` |
| 마스크 POV | `#pov-viewport` CSS 비네팅·눈구멍·실루엣 (3D 아님) |

## 3. 기획서에 있으나 아직 없는 것

| 기획서 | 상태 |
|---|---|
| 심문실 3D / 실사급 POV | CSS 연출만 (3D는 이후) |
| SELECT 제한 시간 (8초 등) | **60초** 카운트다운 + 자동 확정 (프로토 검증용 연장) |
| 무승부 아이템 **선착순 경쟁** / 손 체력 | 프로토타입 확정 룰(나 1 + CPU 1)으로 대체 |
| 독방 꾸미기, 메타 로어, 탈옥 엔딩 | 미착수 |
| 멀티플레이 (실제 1:1 PvP) | CPU only |
| Playwright 자동 테스트 | `tests/smoke-menu.mjs` 초안만 |

## 4. 기획서에 없었던 것 — 프로토타입·제안으로 추가

### 4.1 프로젝트·기술

| 항목 | 설명 |
|---|---|
| HTML 바닐라 JS | Godot 대신 웹 프로토타입 |
| `prototype/` 폴더 | docs와 실행 코드 분리 |
| Step 0~6 로드맵 · 버전 **0.1.x** | 구현·문서 버전 |
| `run.bat` | `run.ps1` + `serve.py`(JS no-store) · 브라우저 오픈 · Ctrl+C/키 종료 |
| ES Module 구조 | `game/` `ui/` `scenes/` `core/` |
| `#event-log` + `replay` | 디버그 문자열 + VHS 구조화 이벤트 |
| `main.js` dispatch | `reducePhase` + `render` (`event-bus`는 stub) |
| boot 순서 | UI 핸들러 선등록 → `preloadAudio` 비차단 |

### 4.2 게임 UX

| 항목 | 설명 |
|---|---|
| 승리 → 독방 / 패배 → 게임오버 | 기획서 「독방 복귀」를 승리에만 연결 |
| `[다음 상대]` / `[타이틀]` | cell 씬 |
| 선택 0.5초 debounce 후 확정 | SELECT UX |
| REVEAL 0.8s / RESOLVE 1.2s | `core/timing.js` |
| `[유지]` + R/P/S로 변경 | ADJUST UX · **한 번 확정** (`playerAdjusted`) |
| ADJUST **순서** (0.1.37) | 동전: **입력으로 시작** → 첫 선공 · 턴마다 교대 · 「이번 수정」 (`0.1.37`) |
| 버튼 순서 **가위·바위·보** | `button-panel.js` |
| ADJUST 확정 표시 | 유효 패·유지/페이크에 노란 테두리 (`is-committed`) |
| ADJUST 조기 종료 | 나·상대 모두 결정 완료 → 즉시 RESOLVE |
| ADJUST 상대 버튼 안내 | 기본 유지/바꾸기(페이크 위장) · 본능·가면은 페이크까지 (`opponentButtonHint`) |
| CPU ADJUST | `planCpuAdjustAction` — 유지|바꾸기|페이크 **최종 1회** |
| REVEAL partialResult 고정 | ADJUST 후에도 천장 문구 불변 |
| 천장·POV 높이 고정 | `--ceiling-height: 100px`, `--pov-viewport-height: 300px` |
| ADJUST 연출 비대칭 | 내 수정·페이크 무음 · **상대 페이크·변경** SFX+플래시 |

### 4.3 Step 4 규칙

| 항목 | 설명 |
|---|---|
| 페이크 자원 1회 | `bluffs` (가면으로 +1 가능) |
| TIE_LOOT | 선택 후 [획득] · 나 1 + CPU 1 |
| **규칙 파괴** | REVEAL/ADJUST에서 상대 초기 패 공개 |
| Web Audio / WAV | `metal-click.wav`(SELECT), `metal-bluff.wav`(**상대 페이크**) + 폴백 |

### 4.4 Step 6 메타

| 항목 | 설명 |
|---|---|
| 가면 4종 | ☺ 수정권+1 · ? 페이크+1 · × 첫 ADJUST **본능형** 힌트 · ◑ 동전 **후공** |
| 장착 | **1개**, cell 벽면에서 수동 장착 · 설명 문구 표시 |
| VHS | CRT 텍스트 타임라인 (재생·스크럽·되감기) + 사용 안내 |
| matchHistory | 최근 5매치 |
| CPU replay | `(hidden)` 텍스트 표시 |
| 세이브 UX | 타이틀 새 게임(인라인 확인) / 이어하기 |
| 디버그 | 개발자 모드 토글 → 강제 승리·패배 |

## 5. 기획서와 의도적으로 다른 것

| 항목 | 기획서 | 프로토타입 |
|---|---|---|
| 무승부 아이템 획득 | 선착순 vs 자원 (논의 중) | **나 1개 + CPU 1개** |
| 아이템 3종 | 본능, 시간 팽창 등 | instinct / time_warp / **rule_break** |
| 패배 누적 상한 | 「3~4회」 | **3회** |
| 독방 복귀 | 매치 종료 후 | **승리 시에만** cell (패배는 gameover) |
| 가면 장착 | 시너지·복수 가능 암시 | **동시 1개** |
| VHS | 물리 캠코더·영상 | 텍스트 타임라인 + (선택) SFX |
| ADJUST 순서 | (명시 약함 · 동시 수정에 가까움) | **동전 의식 + 턴 교대:** 첫 선공 50/50 · 이후 스왑 (`initiative`) |

> **참고:** 초기에 HP 3→0 방식을 시험했으나, 기획서 형벌 누적(0→3)으로 확정.

## 7. 앞으로 결정이 필요한 것

- 무승부 아이템: 선착순 vs 자원 소모 (프로토타입은 확정 룰 유지 중)
- 페이크: 자원·쿨다운·상대 청취 범위
- SELECT 제한 시간 적용 여부
- ADJUST 선/후: ~~최초 매치 강제 후공 가면~~ → **0.1.38 뒷면 가면** (`force_second`)
- 가면 시너지(2개+)·추가 능력 목록
- HTML → Godot 이관 시점
- 독방 하우징 / 로어 / 탈옥 엔딩
