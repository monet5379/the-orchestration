**한 줄 요약**
**ADJUST**를 **15초**로 줄이고, 상대가 누른 버튼을 **유지/바꾸기**(본능·가면은 페이크까지)로 알려 주며, 타이틀·로컬 서버 실행을 안정화했습니다.

---

**이번 빌드 변경 사항**

**ADJUST 시간**
• **30초 → 15초** (시간 팽창 +2초 → **17초**)

**상대 버튼 안내**
• 기본: `상대가 유지/바꾸기 버튼을 눌렀습니다.` (페이크는 **바꾸기로 위장**)
• **본능** / **×가면**(1턴): 유지 · 바꾸기 · **페이크**를 정확히 표시
• 상태 필드 `opponentButtonHint` (`kept` | `changed` | `bluffed`) — 진실값 저장, UI에서만 위장

**CPU ADJUST (안내 1회)**
• 유지 / 바꾸기 / 페이크를 **미리 한 번** 정한 뒤 커밋 (`planCpuAdjustAction`)
• 유지→페이크 2단으로 안내가 덮어쓰이던 현상 제거

**타이틀 · 부트**
• 새 게임: `window.confirm` 대신 **인라인 확인**(삭제하고 시작 / 취소)
• 메뉴 `phase`를 SELECT와 분리 → 타이틀에서 매치 진입 시 SELECT 타이머 부트 보장
• 모듈 캐시로 named export 불일치가 나던 경우 대비 (`?v=` + **serve.py no-store**)

**로컬 런처**
• `run.bat` → `run.ps1` (숨김 서버 프로세스 · Ctrl+C/아무 키로 정리)
• `serve.py`: JS/CSS/HTML `Cache-Control: no-store`
