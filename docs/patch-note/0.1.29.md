**한 줄 요약**
**ADJUST**(수정 페이즈)에서 유지·변경·페이크는 **한 번이면 끝**이고, 나와 상대가 모두 결정을 마치면 **즉시 RESOLVE**로 넘어갑니다.

---

**이번 빌드 변경 사항**

**ADJUST 확정 UX**
• 유지 / 변경 / 페이크 중 **하나만** 가능 — 결정 후 가위·바위·보·유지·페이크 **전부 잠금**
• 노란 테두리(`is-committed`) — **현재 유효 패**(`finalChoice`) 버튼에 표시
• 유지·페이크는 패 버튼 표시가 같으므로, **누른 쪽(유지 또는 페이크) 버튼**에도 같은 강조
• 변경 시 — 새로 고른 패에만 노란 테두리 · 추가 변경 불가

**조기 종료**
• `playerAdjusted` + `cpuAdjusted` 모두 완료되면 남은 타이머를 끊고 **즉시 `ADVANCE_TO_RESOLVE`**
• 시간 초과 시 — 아무 결정 없어도 기존처럼 현재 패로 RESOLVE (최대 **30초**, 시간 팽창 시 32초)

**상태**
• `playerAdjusted`: `false` | `'kept'` | `'changed'` | `'bluffed'`
