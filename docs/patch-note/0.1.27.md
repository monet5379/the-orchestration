**한 줄 요약**
가위바위보 심리전(5초 수정·페이크)과 승리 후 **독방**에서 가면·VHS로 이어가는 메타 루프까지 포함된 첫 공유 빌드입니다.

---

**이 빌드에서 할 수 있는 것**

**매치**
• 가위·바위·보 + 5초 **ADJUST**(수정 페이즈: 유지 / 변경 / 페이크)
• 천장에는 「승자 있음 / 무승부」만 공개 · 페널티 **3회**로 승패
• **ADJUST**(수정 페이즈) — 수정권 있을 때 **현재 패 버튼 비활성** (다른 두 패만 변경)
• 무승부 시 아이템 1개
　– 본능 — 다음 턴 **ADJUST**(수정 페이즈) 중 상대가 패를 바꿨는지 힌트 (페이크도 변경으로 감지)
　– 시간 팽창 — 다음 턴 **ADJUST**(수정 페이즈) 시간 +2초
　– 규칙 파괴 — 다음 턴 **REVEAL**(상황 공개)에서 상대 초기 패 공개
• 마스크 POV · POV 안 HUD · SELECT(패 선택) 선택 시 금속음·플래시
• **상대 페이크**만 페이크음 + 빨간 렌즈 플래시 (내 수정·페이크는 무연출)

**독방 · 메타**
• 승리 → **독방** · 패배 → 게임오버
• 가면 수집·장착 1개
　– ☺ 웃는 가면 — 매치 시작 시 수정권 +1
　– ? 물음 가면 — 매치 시작 시 페이크 +1
　– × 엑스 가면 — 첫 **ADJUST**(수정 페이즈)에 본능형 힌트
• VHS로 직전 매치 복기 (CPU 행동은 hidden)
• localStorage — 가면 · 전적 · 최근 5매치

**타이틀 · 디버그**
• **[이어하기]** / **[새 게임]** (세이브 요약 표시)
• 매치 **[개발자 모드]** — 강제 승리 / 강제 패배

---

**플레이 흐름**
`메뉴(새 게임/이어하기) → 매치 → 승리 → 독방 → 다음 상대`
`　　　　　　　　　　　　　↘ 패배 → 게임오버 → 다시 하기`
