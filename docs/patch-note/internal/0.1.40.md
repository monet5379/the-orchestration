# Internal · v0.1.40

**날짜:** 2026-08-31  
**범위:** 시간 팽창 아이템 삭제 · `timers.timeWarpBonusSec` 제거  
**제품 표시:** 아직 `0.1.39`일 수 있음 — 다음 **외부 배포** 시 `index.html` / `main.js?v=` / console를 그 배포 번호에 맞출 것

프로그래머용. **플레이어 체감 있음** → 배포 시 외부 패치노트에 포함할 후보.

ADJUST가 15초로 늘어난 뒤 시간 팽창(+2s) 효용이 낮아져 아이템·밸런스 키를 제거한다.

---

## 규칙 변경 요약

| 종류 | 내용 |
|------|------|
| **remove** | TIE 아이템 `time_warp` (시간 팽창) |
| **change** | 무승부 아이템 풀: 본능 · 규칙 파괴 (**2종**) |
| **remove** | `timers.timeWarpBonusMs` / 시트 `timers.timeWarpBonusSec` |
| **change** | `getAdjustDurationMs()` → 항상 `timers.adjustMs` (state 불필요) |

---

## 밸런스

| 키 | 조치 |
|----|------|
| `timers.timeWarpBonusMs` | defaults · `balance.json` · `SHEET_KEY_MAP`에서 삭제 |
| `timers.timeWarpBonusSec` | 시트 행 삭제 필요 (맵 제거 후; 남아 있어도 무시됨) |
