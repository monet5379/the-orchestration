## 밸런스 (`getBalance()`)

런타임 단위: **ms**, 확률 **0~1**. 기본값은 0.1.30과 동일.

| 키 | 기본값 | 용도 |
|----|--------|------|
| `meta.version` | `1` | 로드 확인용 (시트 연동 시) |
| `timers.selectMs` | `60000` | SELECT 제한 |
| `timers.adjustMs` | `15000` | ADJUST 기본 |
| `timers.timeWarpBonusMs` | `2000` | 시간 팽창 보너스 |
| `match.maxPenalties` | `3` | 매치 종료 페널티 |
| `match.startChanges` | `2` | 시작 수정권 |
| `match.startBluffs` | `1` | 시작 페이크 |
| `ai.adjustChanceOnDraw` | `0.25` | 무승부 공개 후 변경 확률 |
| `ai.adjustChanceWhenWinner` | `0.55` | 승패 갈린 뒤 변경 확률 |
| `ai.bluffChance` | `0.45` | 페이크 확률 |
| `ai.adjustDelayMinMs` / `MaxMs` | `1000` / `4000` | CPU ADJUST 지연 |
| `ai.bluffDelayMinMs` / `MaxMs` | `300` / `1100` | 페이크 시 추가 지연 |

확률은 `Math.random() < chance` (이전 `> (1 - chance)` 역치와 동일 분포).

CPU delay: `uniform(adjustMin, adjustMax)` + (bluffed면 `uniform(bluffMin, bluffMax)`).
