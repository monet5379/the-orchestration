## 로드 계약


| 항목              | 내용                                                      |
| --------------- | ------------------------------------------------------- |
| 기본 URL          | 구글 시트 `pub?output=csv`                                  |
| 시트 단위           | 시간 **초**, 확률 0~1, 개수 숫자                                 |
| 런타임             | **ms** / 확률 0~1                                         |
| 성공(시트)          | source = `sheet`                                        |
| 시트 실패 → JSON 성공 | source = `json`                                         |
| 둘 다 실패          | `current` 불변, source 유지                                 |
| 캐시              | `fetch(..., { cache: 'no-store' })` (Google CDN 지연은 별개) |
| 확인              | 로컬 HTTP 서버 권장 (`file://` CORS 실패 가능)                    |
