# Internal · v0.1.41

**날짜:** 2026-08-31  
**범위:** ADJUST 선공·적 후공 — CPU 확정 후 버튼 안내 연출(고민→선택) · `ai.adjustRevealHoldMs`  
**제품 표시:** 아직 `0.1.39`일 수 있음 — 다음 **외부 배포** 시 `index.html` / `main.js?v=` / console를 그 배포 번호에 맞출 것

프로그래머용. **플레이어 체감 있음** → 배포 시 외부 패치노트에 포함할 후보.

선공일 때 CPU가 후커밋하면 `maybeAdvanceAdjustEarly`가 즉시 RESOLVE로 넘어가 버튼 안내가 거의 안 보였다. 확정 직후 연출 비트를 끼운다.

---

## 규칙 변경 요약

| 종류 | 내용 |
|------|------|
| **add** | `opponentAdjustBeat: null \| 'thinking' \| 'revealed'` |
| **add** | `SET_OPPONENT_ADJUST_BEAT` — 연출 비트 전환 |
| **change** | 선공 + `CPU_*` + 양측 확정 → 즉시 RESOLVE 금지 · `beginOpponentRevealHold` |
| **add** | 고민(~hold) → 버튼 안내(~hold) → `ADVANCE_TO_RESOLVE` |
| **keep** | 후공 경로(상대 선커밋 → 내 타이머) 변경 없음 |

---

## 밸런스

| 키 | 기본 | 의미 |
|----|------|------|
| `ai.adjustRevealHoldMs` / 시트 `ai.adjustRevealHoldSec` | 1000 / **1** | 고민·안내 **각** 비트 유지(ms/초) |

시트에 행이 없으면 CSV 로드 실패 → 로컬 `balance.json` fallback.
