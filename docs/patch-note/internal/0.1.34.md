## 액션 · 흐름

### ADJUST (후공)

1. `ENTER_ADJUST` → `beginOpponentAdjustTurn`
   - `showOpponentTurnWait` (틱 없음)
   - `planCpuAdjustAction` + `ai.*Delay*` 후 `CPU_ADJUST` / `CPU_BLUFF`
2. CPU 확정 → `applyOpponentButtonHint` → `beginPlayerAdjustTurn`
   - `startAdjustCountdown(..., adjustTimerMs → ADVANCE_TO_RESOLVE)`
3. 플레이어 `ADJUST_*` 1회 또는 타임아웃 → RESOLVE
4. `maybeAdvanceAdjustEarly`: `playerAdjusted && cpuAdjusted`만 (CPU만 끝나도 RESOLVE 안 함)

### 가드

- `ADJUST_CHANGE` / `ADJUST_CONFIRM` / `ADJUST_BLUFF`: `isWaitingForOpponentAdjust`이면 no-op
- `canAdjustChange` / `Confirm` / `Bluff`: `waitingForOpponent`면 `false`
- `setButtonPanelEnabled(..., waitingForOpponent)`

### SELECT / REVEAL

변경 없음 (동시 패 · `partialResult`).
