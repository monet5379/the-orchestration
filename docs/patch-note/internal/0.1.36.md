# Internal · v0.1.36

**날짜:** 2026-08-30  
**범위:** ADJUST 선공 — 매치 시작 동전(첫 턴) + 이후 턴마다 교대 · 기존 선공/후공 경로 유지  
**제품 표시:** 아직 `0.1.30`일 수 있음 — 다음 **외부 배포** 시 `index.html` / `main.js?v=` / console를 그 배포 번호에 맞출 것 (버전 규칙: `docs/patch-note/internal/README.md`)

프로그래머용. **플레이어 체감 있음** → 배포 시 외부 패치노트에 포함할 후보.

SELECT는 동시 유지. 강제 후공 가면은 **미포함** (후속). 선공/후공 분기 코드는 삭제하지 않음.

| 종류 | 내용 |

| **add** | UX: matchLog `[매치] 첫 수정: 선공/후공` · ADJUST 「이번 수정: 선공/후공」 |

안내 문구 규칙(공개 위장 · 본능/× 진실)은 0.1.30과 동일.

| 필드 | 타입 | 의미 |

초기화: `state.js` `createMatchState`. 턴 진행: `advanceToNextTurn`에서 토글.

## 액션 · 흐름

### 매치 시작

1. `createMatchState` → `initiative` 50/50
2. `initMatchFromOptions` → log `[매치] 첫 수정: 선공|후공`

### ADJUST (선공 · `initiative === 'player'`)

0.1.35와 동일: `beginPlayerAdjustTurn` → 확정 후 CPU → 안내.

### ADJUST (후공 · `initiative === 'opponent'`)

0.1.34와 동일: `beginOpponentAdjustTurn` → CPU → `beginPlayerAdjustTurn`.

### 다음 턴

`advanceToNextTurn`: `initiative` 뒤집기 + log `[턴 N] SELECT · 이번 수정: 선공|후공`.

### SELECT / REVEAL

변경 없음 (동시 패 · `partialResult`).
