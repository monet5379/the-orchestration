## 액션 · 흐름

### 매치 시작 (동전 의식)

1. `createMatchState` → `initiative` 50/50 · `coinPending: true`
2. `initMatchFromOptions` → log `[매치] 첫 수정: 선공|후공`
3. `beginCoinCeremony` — 버튼 잠금 · SELECT 타이머 미시작  
   - ~0.6s `REVEAL_COIN` → 「첫 수정: …」  
   - ~1.4s `FINISH_COIN` → `beginSelectPhase`  
   - 스킵: 즉시 `FINISH_COIN` + SELECT
4. SELECT 동시 패 선택

### ADJUST (선공 · `initiative === 'player'`)

0.1.35와 동일: `beginPlayerAdjustTurn` → 확정 후 CPU → 안내.

### ADJUST (후공 · `initiative === 'opponent'`)

0.1.34와 동일: `beginOpponentAdjustTurn` → CPU → `beginPlayerAdjustTurn`.

### 다음 턴

`advanceToNextTurn`: `initiative` 뒤집기 + log `[턴 N] SELECT · 이번 수정: 선공|후공`. **동전 의식 없음.**

### SELECT / REVEAL

SELECT는 동시. `coinPending` 중 `SELECT_*` no-op.
