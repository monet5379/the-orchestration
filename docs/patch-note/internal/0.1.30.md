## 액션 · 흐름

### SELECT
- `beginSelectPhase` (`main.js`): `SELECT_DURATION_MS` 카운트다운 (ADJUST 타이머 UI 재사용)
- 타임아웃 `onSelectTimeout`: `choice` 없으면 무작위 `SELECT_MOVE` → `COMMIT_SELECT`

### ADJUST 플레이어
- `ADJUST_KEEP` / `ADJUST_CHANGE` / `ADJUST_BLUFF` (`phases.js`): 이미 `playerAdjusted`면 no-op
- 커밋 후 `button-panel.setButtonPanelEnabled(..., playerAdjusted)` → 전부 잠금
- `is-committed`: `finalChoice` 패 버튼 + (kept면 유지 / bluffed면 페이크) 액션 버튼

### ADJUST CPU
- `planCpuAdjustAction(state)` → `{ kind: 'kept' | 'changed' | 'bluffed', move? }`
- `beginAdjustPhase`에서 plan 확정 후 지연 커밋 1회 (`CPU_ADJUST` / `CPU_BLUFF` / keep 경로)
- `applyOpponentButtonHint`: hint가 이미 있으면 **덮어쓰지 않음**

### 조기 / 만료 RESOLVE
- `maybeAdvanceAdjustEarly`: `playerAdjusted && cpuAdjusted` → `clearAllTimers` → `ADVANCE_TO_RESOLVE`
- 타이머 만료: 미결정이어도 `ADVANCE_TO_RESOLVE` (기존 패로 진행)

### 상대 버튼 안내 (UI)
| 조건 | 표시 | 함수 |
|------|------|------|
| 기본 | 페이크 → **바꾸기** 위장 | `getPublicOpponentButtonText` (`items.js`) |
| 본능 | 진실 (유지/바꾸기/페이크) | `getInstinctDisplayHtml` |
| ×가면 1턴 | 본능과 동일 타이밍·문구 | `getMaskInstinctDisplayHtml` |
