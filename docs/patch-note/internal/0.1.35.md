# Internal · v0.1.35

**날짜:** 2026-08-30  
**범위:** ADJUST 선공 고정 — 플레이어 선커밋 → CPU 후커밋 · 후공 분기 코드 유지  
**제품 표시:** 아직 `0.1.30`일 수 있음 — 다음 **외부 배포** 시 `index.html` / `main.js?v=` / console를 그 배포 번호에 맞출 것 (버전 규칙: `docs/patch-note/internal/README.md`)

프로그래머용. **플레이어 체감 있음** → 배포 시 외부 패치노트에 포함할 후보.

SELECT는 동시 유지. 동전·강제 후공 가면은 **미포함** (후속). 후공 경로(`initiative === 'opponent'`)는 삭제하지 않음.

| 종류 | 내용 |
|------|------|
| **change** | `initiative` 기본값 `'player'`(선공) — 매치 생성 시 고정 |
| **change** | ADJUST 선공: 「내 턴」+ 플레이어 타이머 즉시 → 확정 후 CPU plan 커밋 → 안내 |
| **add** | `scheduleCpuAdjustCommit` — 후공 진입·선공 확정 후 공유 |

안내 문구 규칙(공개 위장 · 본능/× 진실)은 0.1.30과 동일. 선공 중 `opponentButtonHint`가 없을 수 있음(정상).

| 필드 | 타입 | 의미 |

## 액션 · 흐름

### ADJUST (선공 · 기본)

1. `ENTER_ADJUST` → `beginPlayerAdjustTurn`
   - 「내 턴」·패널 해금·`adjustTimerMs` 즉시 시작
2. 플레이어 `ADJUST_*` 1회 → `beginCpuAdjustAfterPlayer`
   - 타이머 중단 · `showOpponentTurnWait` · `scheduleCpuAdjustCommit`
3. CPU 확정 → `applyOpponentButtonHint` → `maybeAdvanceAdjustEarly`
4. 플레이어 미확정 타임아웃 → `ADVANCE_TO_RESOLVE` (양측 유지)

### ADJUST (후공 · 분기 유지)

`initiative === 'opponent'`일 때만 0.1.34와 동일: `beginOpponentAdjustTurn` → CPU → `beginPlayerAdjustTurn`.

### 가드

- `isWaitingForOpponentAdjust`: `initiative === 'opponent' && !cpuAdjusted` (선공에서는 false)
- `maybeAdvanceAdjustEarly`: `playerAdjusted && cpuAdjusted`만

### SELECT / REVEAL

변경 없음 (동시 패 · `partialResult`).
