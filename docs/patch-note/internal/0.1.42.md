# Internal · v0.1.42

**날짜:** 2026-08-31  
**범위:** 무승부 ADJUST — CPU 바꾸기 시 카운터 패 고정 (`pickBeatingMove`)  
**제품 표시:** 아직 `0.1.39`일 수 있음 — 다음 **외부 배포** 시 `index.html` / `main.js?v=` / console를 그 배포 번호에 맞출 것

프로그래머용. **플레이어 체감 있음** → 외부 [`../external/0.1.42.md`](../external/0.1.42.md).

무승부에서 CPU가 바꾸기를 쓰면 나머지 2패 중 랜덤이 아니라, **당시 패를 이기는 패**로만 바꾼다.  
바꾸기 **여부** 확률(`ai.adjustChanceOnDraw`)은 그대로.

---

## 규칙 변경 요약

| 종류 | 내용 |
|------|------|
| **add** | `pickBeatingMove(current)` — 가위→바위 · 바위→보 · 보→가위 |
| **change** | `planCpuAdjust`: `partialResult === 'draw'`이면 `pickBeatingMove`, 아니면 기존 `pickDifferentMove` |
| **keep** | `decideAdjust` / `adjustChanceOnDraw` · 승자 있음 시 랜덤 바꾸기 · 페이크 |

---

## 동작

| `partialResult` | 바꾸기 대상 |
|-----------------|-------------|
| `draw` | 현재 CPU 패를 이기는 패 **고정** |
| `winner_exists` | 현재와 다른 패 중 **균등 랜덤** (기존) |

플레이어가 ADJUST에서 같이 바꾸면 최종 승패는 달라질 수 있음 (의도: 무승부 **당시** 패 기준 카운터).

## 회귀 포인트

- [ ] 무승부(가위) + CPU 바꾸기 → 반드시 바위
- [ ] 무승부(바위) + CPU 바꾸기 → 반드시 보
- [ ] 무승부(보) + CPU 바꾸기 → 반드시 가위
- [ ] 무승부에서 바꾸지 않음 / 페이크 / 유지 비율은 기존 확률과 체감 동일
- [ ] 승자 있음 + CPU 바꾸기 → 여전히 나머지 2패 중 랜덤
