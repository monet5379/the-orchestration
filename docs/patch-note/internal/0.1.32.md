## 규칙 변경 요약

| 종류 | 내용 |
|------|------|
| **add** | `loadBalance(url?)` — fetch → shape 검증 → `current` 교체; 실패 시 기존 값 유지 |
| **add** | `BALANCE_URL` · `getBalanceSource()` · `formatBalanceMeta()` |
| **add** | `prototype/data/balance.json` (기본값과 동일 수치) |
| **change** | `boot` / 타이틀 복귀(`returnToTitle` · `onLeaveCell`)에서만 로드; 매치 중 미호출 |
| **add** | 타이틀 `#menu-balance-meta` — `balance v{n} · json\|defaults` |

구글 시트 연동·초 단위 입력 변환은 **미포함** (3번). `BALANCE_URL` 또는 `loadBalance(url)`만 바꾸면 되게 인터페이스만 맞춤.

---

## 로드 계약

| 항목 | 내용 |
|------|------|
| 기본 URL | `./data/balance.json` |
| 성공 | `getBalance()` = 로드 객체, source = `json` |
| 실패 | `current` 불변 (초기면 `BALANCE_DEFAULTS`), source 유지 |
| 시점 | 부팅 1회 + 타이틀 복귀; SELECT/ADJUST 등 매치 중 재fetch 없음 |
| 런타임 단위 | 여전히 **ms**, 확률 **0~1** (JSON도 동일) |
